# 今日项目（初学者版）：简易待办清单

之前那个版本用到了 `argparse`、JSON、列表推导式等**进阶语法**，对刚开始学 Python 的同学偏难。
这个版本**只用最基础的知识**重写：变量、列表、字典、while 循环、if/elif、input/print、函数、f-string。

## 运行方法

在该文件夹打开终端：

```bash
python todo.py
```

然后按提示输入数字：`1` 添加待办、`2` 标记完成、`3` 退出。

## 代码里用到的每个知识点（大白话版）

### 1. 变量 —— 给数据起个名字
```python
todos = []      # 把"空列表"存进变量 todos，之后都通过它操作
text = "写作业"  # 把字符串存进变量 text
```

### 2. 列表 list —— 一排数据的"收纳盒"
```python
todos = []            # 一个空的收纳盒
todos.append("写作业") # 往盒子里放东西（总是加到末尾）
len(todos)            # 数一数盒子里有几样
todos[0]              # 取第 1 个（注意：下标从 0 开始）
```

### 3. 字典 dict —— 一条数据里装多个信息
```python
t = {"text": "写作业", "done": False}   # 一条待办：内容是"写作业"，还没完成
t["text"]            # 取出内容 -> "写作业"
t["done"] = True     # 修改：把它标记为完成
```

### 4. while 循环 —— 让一段代码反复执行
```python
while True:      # 条件永远是 True，所以会一直循环
    ...          # 循环体
    break        # 一遇到 break 就跳出循环
```

### 5. if / elif / else —— 根据条件走不同的路
```python
if choice == "1":
    add_todo()        # 用户输入 1：去添加
elif choice == "2":
    done_todo()       # 用户输入 2：去标记完成
elif choice == "3":
    break             # 用户输入 3：退出
else:
    print("输入有误")  # 其他情况
```

### 6. input() / print() —— 和程序对话
```python
text = input("请输入：")   # 程序停下来等用户打字，回车后得到字符串
print("你好", text)        # 把内容显示到屏幕上
```

### 7. 函数 def —— 把一段功能打包，起个名字
```python
def add_todo():    # 定义函数：名字叫 add_todo
    ...            # 函数体：每次调用都会执行这里
add_todo()         # 调用函数
```
好处：把"添加""显示""完成"各自打包成一个函数，程序结构清晰，以后想加功能就新写一个函数。

### 8. f-string —— 在字符串里插入变量
```python
name = "小明"
print(f"你好，{name}")   # 输出：你好，小明
```
