## 新知识点①：字典推导式

和列表推导式套路一样，只是生成的是**字典（键值对）**：

```python
{x: x ** 2 for x in range(5)}
# -> {0: 0, 1: 1, 2: 4, 3: 9, 4: 16}

{ch: password.count(ch) for ch in unique}
# -> {'a': 2, 'b': 1, ...} 每个字符出现几次
```
写法：`{键的表达式: 值的表达式 for 变量 in 可遍历的}`

## 新知识点②：集合推导式

生成的是**集合**（自动去重、无序）：

```python
{ch for ch in "hello"}
# -> {'h', 'e', 'l', 'o'}（重复的 l 只剩一个）

{random.randint(1, 6) for _ in range(10)}
# -> 掷 10 次骰子，自动去重后出现过的点数
```

## 推导式三兄弟总结（背下来！）

| 推导式 | 写法 | 生成 | 特性 |
| --- | --- | --- | --- |
| 列表推导式 | `[表达式 for x in ...]` | 列表 | 有序、可重复、可改 |
| 集合推导式 | `{表达式 for x in ...}` | 集合 | 自动去重、无序 |
| 字典推导式 | `{键: 值 for x in ...}` | 字典 | 键值对 |

看到 `[ ]` `{ }` `{k: v}` 开头，就知道生成的是什么了。
