## 新知识点：列表推导式（重点）

### 它解决什么问题？
以前生成新列表要 3 行：
```python
evens = []
for x in nums:
    if x % 2 == 0:
        evens.append(x)
```
用推导式**一行**搞定：
```python
evens = [x for x in nums if x % 2 == 0]
```

### 基本形：变换
```python
[x ** 2 for x in [1, 2, 3]]      # -> [1, 4, 9]
[x * 2 for x in [1, 2, 3]]       # -> [2, 4, 6]
[s.upper() for s in ["a", "b"]]  # -> ["A", "B"]（字符串也能用）
```

### 带 if：筛选
```python
[x for x in [1, 2, 3, 4] if x % 2 == 0]    # -> [2, 4]
[x for x in [1, 2, 3, 4] if x > 2]         # -> [3, 4]
```

### 拆开读
`[表达式 for 变量 in 列表 if 条件]`
- `for 变量 in 列表` —— 循环遍历（必写）
- `表达式` —— 每个元素怎么变（必写）
- `if 条件` —— 只要符合条件的（可选）

### 三个注意
1. 生成的是**新列表**，原来的列表不变
2. 别写太复杂的逻辑进去，超过两三行就回归普通 for 循环
3. 可读性优先——推导式是给"能一眼看懂"的简单变换用的

## 小知识

列表推导式之外还有**字典推导式** `{k: v for ...}` 和**集合推导式** `{x for ...}`，套路完全一样。学会了它，你会开始看懂网上很多"一行流"的 Python 代码——这就是 Pythonic 的魅力。
