# 今日项目（11-09）：身份证信息查询器

输入一个 18 位身份证号，程序自动提取出生日期、性别、地区代码。
今天的核心新知识是**字符串切片**——从字符串里"切"一段出来，这是处理文本最常用的本领之一。

## 运行方法

在该文件夹打开终端：

```bash
python idcard.py
```

输入 18 位身份证号（自己编一个也行，程序会检查格式），输入 `q` 退出。

> 小知识：身份证 18 位结构 = 前 6 位地区代码 + 第 7~14 位出生日期 + 第 15~17 位顺序码（第 17 位奇男偶女）+ 第 18 位校验码。

## 新知识点①：字符串切片 s[start:end]（重点）

```python
s = "abcdef"
s[1:4]        # -> "bcd"（含下标 1，不含下标 4）
s[:3]         # -> "abc"（从头切到下标 3 前）
s[3:]         # -> "def"（从下标 3 切到末尾）
s[-1]         # -> "f"（-1 表示倒数第 1 个）
s[::-1]       # -> "fedcba"（步长 -1 = 倒过来，进阶彩蛋）
```
**规则：`[开始:结束]`，开始包含、结束不包含**（`"hello"[1:3]` → `"el"`，不是 `"ell"`）。
这个规则一开始容易记反，多试几次就熟了——`"hello"[1:3]` 记住结果是 `"el"` 就行。

## 新知识点②：.isdigit()（1 行）

```python
"123".isdigit()    # -> True
"12a".isdigit()    # -> False
"".isdigit()       # -> False（空字符串不是数字）
```
判断字符串是不是**全是数字**，做格式校验很常用。

## 复习：已经学过的

- `len(s)` 长度、`int(s)` 转整数
- `% 2` 判断奇偶（`s[16]` 是第 17 位，奇数=男）
- `s[17] in "xX"` —— `in` 判断字符在不在字符串里（小补充）
- `.lower()` 统一大小写、`continue` 跳过本次循环回到开头（小补充）
