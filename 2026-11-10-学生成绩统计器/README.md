## 新知识点①：遍历字典 —— items() / values()

之前我们遍历列表，现在遍历字典。字典是一堆"键 → 值"：

```python
scores = {"张三": 85, "李四": 92}

scores.items()    # 一对一对地拿出来：[("张三", 85), ("李四", 92)]
scores.values()   # 只拿值：[85, 92]
scores.keys()     # 只拿键：["张三", "李四"]
```

**重点写法**——遍历时把"一对"拆成两个变量：

```python
for name, score in scores.items():
    print(name, score)     # 张三 85 / 李四 92
```

## 新知识点②：enumerate —— 遍历时自动编号

```python
for i, name in enumerate(["张三", "李四"]):
    print(i, name)        # 0 张三 / 1 李四

for i, name in enumerate(["张三", "李四"], 1):   # 第二个参数 = 从几开始
    print(i, name)        # 1 张三 / 2 李四
```
好处：不用再自己维护 `count = 1; count += 1` 这种计数器了。

## 新知识点③（轻量）：sum / max / min

```python
sum([1, 2, 3])   # -> 6
max([1, 2, 3])   # -> 3
min([1, 2, 3])   # -> 1
```
内置函数，不用自己写循环累加/比大小了。
