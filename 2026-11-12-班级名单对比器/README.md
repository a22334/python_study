## 新知识点：集合 set（重点）

### 集合是什么？
```python
s = {1, 2, 3}        # 用花括号 {} 创建
s = set()            # 空集合！注意：{} 是空字典，不是空集合
```

### 两大特性
**1. 自动去重**：
```python
{1, 1, 2, 2, 3}      # -> {1, 2, 3}，重复的自动没了
```
**2. 无序**：集合没有顺序，**不能按下标取**（`s[0]` 会报错）。

### 常用操作
```python
s.add("张三")        # 加元素（重复的自动忽略）
s.remove("张三")     # 删元素（不存在会报错，可用 s.discard() 不报错）
len(s)               # 个数
"张三" in s          # 判断在不在
list(s)              # 转回列表；set(列表) 列表转集合（顺便去重）
```

### 数学运算（今天的重头戏）
```python
a = {"张三", "李四"}
b = {"李四", "王五"}

a & b    # 交集：{"李四"}（两边都有）
a | b    # 并集：{"张三", "李四", "王五"}（所有，不重复）
a - b    # 差集：{"张三"}（只在 a 里）
```

### 对比三兄弟
| 类型 | 写法 | 能改吗 | 有序吗 | 能重复吗 |
| --- | --- | --- | --- | --- |
| 列表 list | `[ ]` | ✅ | ✅ | ✅ |
| 元组 tuple | `( )` | ❌ | ✅ | ✅ |
| 集合 set | `{ }` | ✅（增删） | ❌ | ❌ |

## 小知识

集合底层是**哈希表**，查找一个元素在不在里面非常快（比列表快得多）——所以"判断重复、判断存在"都用集合。应用场景：去重、抽奖不重复、快速查成员。
