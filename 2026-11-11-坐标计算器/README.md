## 新知识点：元组 tuple（重点）

### 元组是什么？
```python
p = (3, 4)       # 用 () 打包一组数据
p[0]             # -> 3（按下标取）
len(p)           # -> 2（有几个元素）
```
它和列表长得像，**但一旦创建就不能修改**：
```python
p[0] = 9         # 报错！TypeError: 'tuple' object does not support item assignment
```

### 为什么要用元组？
- 适合"打包一组**不该变**的数据"：点的坐标、一对一对的 (名字, 分数)
- 防止手滑改坏数据，代码更安全
- 和列表的区别一句话：**列表 `[ ]` 可以改，元组 `( )` 不能改**

### 拆包：把元组拆开
```python
x, y = (3, 4)    # 一行把元组拆成两个变量：x=3, y=4
```

### 函数返回多个值 = 返回元组
```python
def midpoint(p1, p2):
    ...
    return ((x1 + x2) / 2, (y1 + y2) / 2)   # 打包返回

mx, my = midpoint(p1, p2)                   # 调用时直接拆包
```

### 一个坑
```python
t = (1)    # 这不是元组！就是数字 1
t = (1,)   # 这才是一个元素的元组（别忘了逗号）
```

### 遍历元组列表（明天的预告）
```python
movies = [("流浪地球", 2019), ("哪吒", 2019)]
for title, year in movies:      # 每个元素是元组，直接拆包
    print(title, year)
```
