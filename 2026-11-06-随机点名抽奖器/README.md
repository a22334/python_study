## 新知识点①：random 模块（重点）

随机数是编程里超好玩的模块，用法就三个，都很短：

```python
import random                          # 先引入，放在文件最上面

random.choice(["张三", "李四", "王五"])  # 从列表随机挑 1 个 -> 可能输出"李四"
random.sample([1, 2, 3, 4, 5], 3)      # 随机挑 3 个且不重复 -> 可能是 [5, 1, 3]
random.randint(1, 6)                    # 1~6 的随机整数 -> 掷骰子
```

| 写法 | 作用 | 形象比喻 |
| --- | --- | --- |
| `random.choice(列表)` | 随机挑 1 个 | 从盒子里摸一个球 |
| `random.sample(列表, n)` | 随机挑 n 个、不重复 | 摸 n 个球，摸过的放一边 |
| `random.randint(a, b)` | a~b 的随机整数 | 掷骰子/猜数字 |

## 新知识点②：字符串方法 join（轻量）

```python
"、".join(["张三", "李四"])   # -> "张三、李四"
```
把列表里的元素用中间的符号连成一个字符串。`"-".join(["2026", "11", "06"])` 还能拼出 `"2026-11-06"`，做输出和存文件很方便。

## 小练习（试着动手改一改）

1. **掷骰子**：加一个选项，`random.randint(1, 6)` 模拟扔六面骰子，多扔几次看看是不是真的"随机"。
2. **点名不重复**：每抽中一个人，就用 `names.remove(名字)` 把他从名单里删掉，这样一节课不会反复抽到同一个人（注意：名单空了要提示）。
3. **记录带日期**：把中奖记录改成 `2026-11-06：张三、李四、王五` 这样的格式——复习昨天的 `datetime.now().strftime("%Y-%m-%d")`。

## 小知识

random 其实是"**伪随机**"：它基于一个种子算出一串看起来随机的数字，绝大多数场景完全够用。以后学了 `random.seed(数字)`，就能让"随机"结果可复现，做测试和游戏很有用。
