## 新知识点①：文件读写 `open()` / `with`（重点）

### 打开文件，一共分三步
```python
with open("diary.txt", "a", encoding="utf-8") as f:
    f.write("今天学了文件读写\n")
```
拆开看：
- `open("diary.txt", "a", encoding="utf-8")` —— 打开文件
  - 第一个参数：文件名（不存在时"a"模式会自动创建）
  - 第二个参数：**模式**。`"a"`=追加（在末尾加内容）、`"r"`=读取、`"w"`=覆盖重写
  - `encoding="utf-8"`：用中文编码读写，不然中文会乱码
- `as f` —— 把打开的文件起个名字叫 f
- `with ... as ...` —— 用完之后**自动关闭文件**，省心，不用手动 f.close()

### 写入：f.write()
```python
f.write("一行内容\n")    # \n 是换行符
```

### 读取：f.read() / f.readlines()
```python
text = f.read()          # 把整个文件读成一个字符串
lines = f.readlines()    # 按行读成一个列表：["第1行\n", "第2行\n", ...]
```

### 判断文件是否存在：os.path.exists()
```python
import os
if os.path.exists("diary.txt"):   # 存在返回 True，不存在返回 False
    print("有文件")
```

> 为什么用 with？文件用完必须关闭，忘了关可能写不进去或占用文件。`with` 帮你自动关，永远不用操心。

## 新知识点②：datetime —— 自动获取当前日期时间

```python
from datetime import datetime
now = datetime.now()                              # 现在的时刻
now.strftime("%Y-%m-%d %H:%M")                    # 转成 "2026-11-05 15:00" 这样的字符串
```
- `%Y` 四位年份、`%m` 月份、`%d` 日、`%H` 小时（24小时制）、`%M` 分钟
